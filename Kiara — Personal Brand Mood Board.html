01 Three surfaces, one throughline

The character-design page changes the read. This isn't "UX designer who also draws dragons on the side" — it's evidence that dragon/creature design is treated as a real discipline, with its own professional documentation: a bold rounded display face, a plain-spoken intro paragraph ("Every character has something that makes them unique, my job as a character designer is to define those traits..."), then a systematic grid — expression sheet, outfit variants, consistent color story per character. That's the exact information pattern a UX case study uses (concept → rationale → set of screens), just pointed at a blue dragon-humanoid instead of an app. The Instagram feed is where the same creature work is left raw, mid-sketch, in cobalt blue. Three surfaces, one working method: define the traits, then show the system.

06 A layout pattern worth reusing

Heading → one setup line → the grid

The character sheet's own structure — bold statement, one plain-spoken sentence of intent, then a systematic grid of variations — is the same shape as a UX case study, and could become the site's default template for both: a project title, one sentence on the problem, then a grid of screens, expressions, or outfits.

"Sketches shown raw. Systems built clean. Same eye for both."
